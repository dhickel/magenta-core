# Services Specification

## Intended Contract

Services own use-case behavior and hide persistence, transport, filesystem, and model-provider details from callers. `WorkspaceDirectoryService` owns descriptor resolution; explorer, metadata, action logging, execution, tool, prompt, and output services consume `WorkspaceDescriptor` without reconstructing identity. Add service behavior only for concrete user-facing workflows.

## Implemented Operational Services

- `TaskRunLifecycleService` reserves canonical native/task-run identity before dispatch, records operation-key/request-digest results, opens numbered attempts, issues independent monotonic writer claims, and records typed resume/retry/replay and child lineage. Native family rows remain status truth.
- `OutputArtifactService` and `ArtifactReconciliationService` own reserve → stage → verify → create-only publish → reconcile transitions. Final names are transactionally reserved, writer capability is rechecked, integrity facts are durable, and legacy/non-task artifacts remain in place.
- `ArtifactSearchService` and `ArtifactPreviewService` apply `ArtifactAccessContext` before counts, rows, metadata, lineage, or byte access and recheck at byte open. FTS5 is runtime-probed; unsupported deployments return unavailable. Integrity failure suppresses preview/download.
- `TaskRunRetentionService` defaults to `PRESERVE` (keep indefinitely). Soft archive or hard expiry requires explicit scope and remains blocked by active attempts/claims/downloads, references, lineage/legal pins, or unresolved reconciliation.
- `SkillScopeDiscoveryService` and `SkillResolutionService` normalize confined digest-qualified candidates and exact overlays without creating absent roots or disclosing pending candidate content. Root precedence and assignment specificity are independent.
- `SkillTrustService` binds explicit approval to a confined candidate digest and immutable snapshot. No skill is auto-trusted. `AgentSkillActivationService` reads approved snapshot bytes; revocation blocks new activation except persisted same-run resume. Executable authority and package ingestion remain fail-closed while process confinement is unavailable.
- `RunMeasurementRepository` stores each model/tool invocation separately with nullable provider/process facts. `RunSummaryService` normalizes native status into a rebuildable read model, keeps active/unavailable records outside terminal denominators, derives elapsed only from supported facts, and composes bounded audits through exact identifiers.
- `ScheduleService` owns versioned six-field cron/IANA-timezone definitions, revision-qualified firing identities, operation-key digest idempotency, persisted owner/fence claims, retry attempts, restart/misfire handling, and capability-free simulation.
- `EventReactionService` owns revision-qualified dispatch identity, immutable event/template snapshots, operation-key digest idempotency, causation/deduplication, loop/depth/rate suppression, append-only attempts, and capability-free simulation.
- `WorkspaceExplorerService` remains exclusively responsible for confined filesystem operations. Cross-domain run/artifact/skill/runtime/automation panels are composed in web fragments and never added to this service.
- `JobReassignmentService` atomically revoke-and-clones only a queued, unleased, nonterminal project Job assignment with no `JobRun`, a matching expected row version, active project scope, and eligible destination member. Its server-bound operation digest includes actor, action, scope, source, destination, and expected version; successful replay returns the one persisted successor. Source attribution is never rewritten; the successor captures a fresh destination binding and lifecycle reservation. Failure after revoke rolls back the complete operation. Work Task provenance remains deliberately unavailable until its transactional append-attempt participant exists.
